# Image Organization

Store images by topic:

- `assets/images/heroes/`
- `assets/images/events/`
- `assets/images/gear/`
- `assets/images/alliance/`
- `assets/images/items/`

Use lowercase filenames with hyphens, for example:

```text
assets/images/heroes/generation-7/edith.png
assets/images/events/bear-hunt/rally-example.png
```

Reference an image from Markdown with:

```markdown
![Description](/assets/images/events/bear-hunt/rally-example.png)
```
